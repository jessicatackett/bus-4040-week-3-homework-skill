# bus-4040-week-3-homework-skill



## What does the skill do



This is a Claude Skill called `narrow-road-social-captions`. It writes ready-to-post

Instagram/Facebook captions for Narrow Road Western Boutique, the store I work at.

I give it a quick, rough description of a product or update (like "new turquoise

earrings, $28, great for fall") and it hands back a full caption: a hook line, a

couple sentences about the product, a call to action, a set of hashtags, and alt

text for accessibility.



## How does the skill work



The skill is just a `SKILL.md` file with a description (so Claude knows when to use

it) and instructions in the body: a description of Narrow Road's brand voice

(warm, small-town, western touches when they fit), a required caption structure

(hook, body, call to action, hashtags, alt text), a rule about not inventing

details like prices that weren't given, and a worked example. When I ask Claude

for a caption, it reads those instructions and follows the same structure every

time instead of me having to re-explain the brand voice in every conversation.



## Why did I create this skill



I already write captions for Narrow Road as part of my job, and I was retyping the

same kind of prompt (explain the brand voice, ask for hashtags, ask for alt text)

every time I wanted AI help with one. Turning that into a skill means I only had

to think through the voice and structure once, carefully, instead of every time.



## How can the skill be useful later



I can keep using this at my actual job any time I need a caption written fast -

for a restock, a sale, or a random product photo I want to post that day. It also

means anyone else helping with Narrow Road's social media (or a future me who

forgets the exact voice guidelines) can get consistent captions without me

re-explaining the brand every time. More generally, this showed me that a skill

is worth building for any task I do repeatedly with AI where I keep repeating the

same instructions - I could see doing the same thing for LEARN Idaho web content

or other recurring work.
